### 슬라이드 3: 시험 접속 방법

**레이아웃**: 5단계 가로 스텝 다이어그램 + 하단에 실제 화면 캡처

**상단 — 5단계 플로우**:
각 단계를 번호 원(①②③④⑤) + 화살표로 연결

```
①  Quest-On 접속          →  quest-on.co
②  로그인                 →  가입한 계정으로 로그인
③  코드 입력              →  교수님이 알려준 6자리 코드 입력
④  주의사항 확인           →  시험 규칙 읽고 체크박스 2개 선택
⑤  시험 시작 대기          →  교수님이 시작 버튼 누르면 자동 입장
```

**하단 — 실제 화면 2개 나란히**:
- 좌: `student-join-page.png` — 코드 입력 화면
  - 캡션: `"6자리 시험 코드 입력 화면"`
- 우: `student-dashboard.png` — 학생 대시보드
  - 캡션: `"학생 대시보드 — 시험 목록 확인"`

**디자인 노트**:
- 스텝 번호 원은 Primary 색상 배경 + 흰색 숫자
- 화살표는 연한 회색 또는 primary light
- 이미지 크기: 각각 슬라이드 너비의 40% 정도, 그림자 + 둥근 모서리
- 코드 입력 화면이 핵심 — 학생들이 가장 먼저 보는 화면

### 슬라이드 4: 시험 화면 구성 (핵심 슬라이드)

**레이아웃**: 전체 너비 이미지 + 번호 콜아웃 오버레이

**메인 이미지**:
- `student-exam-main.png` — 실제 3패널 시험 화면을 슬라이드 중앙에 크게 배치 (슬라이드 너비의 85-90%)
- 둥근 모서리(12px) + 그림자

**이미지 위에 번호 콜아웃 3개** (원형 번호 뱃지 + 설명 라인):

```
❶ 문제 패널 (좌측)
   → 시험 문제 확인, 문제 간 이동

❷ 답안 작성 패널 (중앙)
   → 서술형 답안 직접 작성, 자동 저장됨

❸ AI 채팅 패널 (우측)
   → AI 도우미에게 질문하며 학습
```

**콜아웃 배치**:
- 이미지 아래 또는 좌측에 ❶❷❸ 설명을 배치
- 또는 이미지에서 각 패널로 향하는 화살표/선 연결

**디자인 노트**:
- 이 슬라이드가 가장 중요 — 학생들이 실제 시험 화면을 미리 봐야 함
- 번호 뱃지: Primary 색상 원(32px) + 흰색 번호
- 슬라이드 제목: `"시험 화면 구성"` (상단 좌측, 작게)
- 이미지를 최대한 크게 보여주는 것이 핵심

### 슬라이드 5: AI 도우미 사용법

**레이아웃**: 좌우 2분할 — DO(허용) vs DON'T(금지)

**슬라이드 제목**: `AI 도우미 활용 가이드`

**좌측 — ✅ 이렇게 활용하세요 (초록 계열)**:
배경: 연한 초록 (`#F0FDF4`)
```
✅  개념 설명 요청
    "디지털 전환의 정의가 뭐야?"

✅  힌트 요청
    "SWOT에서 S가 뭘 의미해?"

✅  답안 구조 상담
    "서론-본론-결론 어떻게 나눌까?"

✅  예시 질문
    "실제 기업 사례 하나만 알려줘"
```

**우측 — ❌ 이건 안 돼요 (빨간 계열)**:
배경: 연한 빨강 (`#FEF2F2`)
```
❌  정답 직접 요청
    "답 써줘" → AI가 거부합니다

❌  답안 대필 요청
    "이 문제 대신 풀어줘" → 거부

❌  무관한 질문
    시험과 관계없는 질문은 답변 불가

❌  다른 문제 정보 요청
    "2번 문제 답 알려줘" → 현재 문제만 지원
```

**하단 강조 박스** (Primary 배경, 흰 텍스트):
```
💡 AI는 "과외 선생님"처럼 힌트와 설명을 줍니다. 직접 답을 쓰지는 않습니다.
```

**디자인 노트**:
- DO/DON'T 각각 카드 형태로, 좌측에 초록/빨강 세로 바(4px)
- 대화 예시는 채팅 버블 느낌으로 표현하면 효과적
- 아이콘: ✅와 ❌를 크고 명확하게

카드 1 — 💾 자동 저장:

30초마다 자동 저장
Ctrl+S로 수동 저장도 가능

### 슬라이드 8: 제출 과정

**레이아웃**: 3단계 가로 플로우 다이어그램

**슬라이드 제목**: `시험 제출 과정`

**3단계 플로우**:

```
┌─────────────────┐     ┌──────────────────┐     ┌─────────────────┐
│  ① 제출 버튼     │ ──→ │  ② 확인 다이얼로그 │ ──→ │  ③ 제출 완료     │
│                 │     │                  │     │                 │
│ 모든 답안 작성 후 │     │ "정말 제출할까요?" │     │ AI 채점 시작     │
│ 상단 "제출" 클릭  │     │ 최종 확인 후 제출  │     │ (1-2분 소요)     │
└─────────────────┘     └──────────────────┘     └─────────────────┘
```

**하단 안내 박스** 2개:

박스 1 (초록 배경):
```
✅ 제출 후 AI가 자동으로 채점합니다 (1-2분 소요)
   채점이 완료되면 리포트 카드를 확인할 수 있습니다
```

박스 2 (주황 배경):
```
⚠️ 한번 제출하면 수정할 수 없습니다
   제출 전에 모든 답안을 꼼꼼히 확인하세요
```

**디자인 노트**:
- 플로우 단계 카드: 흰 배경 + primary border, 번호는 primary 원
- 화살표: primary 색상, 굵기 2px
- "한번 제출하면 수정 불가" 강조

### 슬라이드 9: 자주 묻는 질문 (FAQ)

**레이아웃**: 4-5개 Q&A 목록

**슬라이드 제목**: `자주 묻는 질문`

**Q&A 목록**:

```
Q. 인터넷이 끊기면 어떻게 되나요?
A. 답안은 자동 저장되어 있어서 재접속하면 이어서 작성할 수 있습니다.

Q. AI가 답을 안 알려주는데요?
A. AI는 직접적인 정답 대신 힌트와 설명을 제공합니다. 질문 방식을 바꿔보세요.

Q. 시간이 다 되면 어떻게 되나요?
A. 시간 초과 시 작성한 답안이 자동으로 제출됩니다.

Q. 다른 브라우저/기기로 접속해도 되나요?
A. 하나의 기기에서만 응시해주세요. 다른 기기 접속 시 세션이 끊길 수 있습니다.

Q. 채점은 어떻게 이루어지나요?
A. AI가 1차 자동 채점 후, 교수님이 최종 확인합니다.
```

**디자인 노트**:
- Q는 Bold + primary 색상, A는 Regular + slate-600
- 각 Q&A 사이에 구분선(1px, `#E2E8F0`)

## 참고: 실제 시험 플로우 상세

PPT 제작 시 참고할 수 있는 실제 제품 동작 상세입니다.

### 접속 ~ 시험 시작
1. `quest-on.co` 접속 → 로그인 (Clerk 기반, Google/이메일)
2. 학생 대시보드 → "시험 참여" 또는 직접 코드 입력
3. 6자리 영문+숫자 코드 입력 (OTP 스타일 UI)
4. **Preflight 모달**: 시험 규칙 3가지 요약 + 상세 규칙 + 체크박스 2개 동의
5. **대기실**: "교수님이 시험을 시작하면 자동으로 입장됩니다" — Supabase Realtime으로 자동 감지

### 시험 화면 (3패널)
- **좌측 — 문제 패널**: 문제 번호 뱃지, 문제 텍스트, 요구사항, 채점 기준, 하단 문제 이동 네비게이션 닷
- **중앙 — 답안 패널**: 리치 텍스트 에디터, 30초 자동 저장 + Ctrl+S 수동 저장, 저장 상태 표시기
- **우측 — AI 채팅**: "AI 도우미" 뱃지, 문제별 별도 대화, 사용자(파란) vs AI(회색) 버블, 타이핑 인디케이터

### 타이머 동작
- 상단 헤더에 남은 시간 표시
- 초록(여유) → 주황(5분 이내) → 빨강(1분 이내) → 빨강 깜빡임(30초)
- 시간 0 → 자동 제출

### AI 시스템 동작
- AI는 교수님이 설정한 맥락 내에서만 답변
- 직접 정답 제공 거부 — 힌트, 설명, 구조화 도움만
- 마크다운 + LaTeX 지원
- 벡터/키워드 검색으로 관련 자료 참조 (RAG)

### 보안 감지
- **붙여넣기 감지**: 외부 텍스트 붙여넣기 시 자동 기록 (원본 텍스트, 커서 위치, 전후 상태)
- **탭 이탈 감지**: 브라우저 탭/창 전환 시 기록
- 모든 기록은 교수님 리포트에 포함

### 제출 후
- 확인 다이얼로그 → 최종 제출
- AI 자동 채점 (1-2분)
- 성공 화면 → "리포트 확인하기" 버튼
- 교수님이 AI 채점 결과 리뷰 후 최종 점수 확정
